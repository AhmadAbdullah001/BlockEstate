# Development

Use Node.js 24+ and npm 11+. Install dependencies at the root and in both applications. Use `npm run dev` for both services, `npm run lint` for the frontend, `npm test` for the backend test foundation, and `npm run build` for the Next.js production build.

Do not commit `.env` files or secrets. Do not add blockchain, payment SDK, AI SDK, Redis, or external storage dependencies until the related implementation begins.
